# SecureVault UI Design Plan

This document defines the final UI direction for SecureVault before redesign work starts.

---

## Goal

SecureVault should feel like a small premium hardware password manager.

The UI should be:

- clean
- dark
- minimal
- readable on the small screen
- safe for security actions
- easy to use with only two buttons

---

## Design Style

Visual direction:

- dark cyber/security style
- black background
- cyan/blue accent
- clear cards
- rounded shapes
- simple icons later if possible
- strong contrast
- no clutter

Main colors:

```text
Background: black / near black
Primary text: white
Muted text: gray
Accent: cyan / blue
Danger: red
Success: green
